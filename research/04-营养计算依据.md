# 04 · 营养与热量计算依据

> 目的：产品里"每日目标热量"和"三大营养素目标"是**健康相关**的核心逻辑，不能拍脑袋。
> 本文记录采用的公式、参数、安全钳制规则及出处。
> 检索时间：2026-10-16

---

## 1. BMR：Mifflin-St Jeor 公式（首选）

目前营养学界对普通人群最准确的预测公式之一，优于 Harris-Benedict。

```
男性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5
女性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 − 161
```

参考：[Mifflin–St Jeor 计算器说明](https://www.evigrade.com/en/calculators/mifflin-st-jeor)、[减脂热量计算](https://www.evigrade.com/en/calculators/weight-loss-calories)

**待确认**：是否提供 Katch-McArdle 公式（需要体脂率，`BMR = 370 + 21.6 × 去脂体重`）作为备选——如果用户有体脂秤数据会更准。

---

## 2. TDEE：活动系数

```
TDEE = BMR × 活动系数
```

| 活动水平 | 系数 | 描述 |
|---|---|---|
| 久坐 | 1.2 | 几乎不运动，研究生日常 = 这个 |
| 轻度活动 | 1.375 | 每周 1-3 次轻运动 |
| 中度活动 | 1.55 | 每周 3-5 次中等强度 |
| 高度活动 | 1.725 | 每周 6-7 次 |
| 极高活动 | 1.9 | 体力劳动 / 一天两练 |

> 产品设计提示：学术界普遍认为这些系数会**高估**真实 TDEE。建议默认取"久坐 1.2"，并在 UI 上说明"如果两周后体重没变化，说明 TDEE 估高了，系统会用你的实测数据修正"。

---

## 3. 热量缺口：安全范围

**权威锚点**：低热量饮食（LCD）的标准做法是**在 TDEE 基础上减少 500–1000 kcal/天**，对应每周减重约 0.5–1 kg。
出处：[Medscape《Obesity Treatment & Management》](https://emedicine.medscape.com/article/123702-treatment#2)、[HHS《Losing Weight — What is healthy weight loss?》](https://stage-digitalmedia.hhs.gov/storefront/showContent/5055)

**推荐实现（保守优先）**：

```
缺口 = min(500, TDEE × 0.20)          # 默认目标：每周减 0.5 kg 左右
速度约束：每周减重 ≤ 体重 × 1%          # 上限，防止掉肌肉
热量下限：男 ≥ 1500 kcal，女 ≥ 1200 kcal
若 (TDEE − 缺口) < 下限 → 取 下限，并提示"已经是安全下限，建议靠增加活动量而不是继续少吃"
```

参考方向：[Achieving an Optimal Fat Loss Phase in Resistance-Trained Athletes (Helms et al.)](https://europepmc.org/article/MED/34579132) — 减脂期应控制速度以避免去脂体重流失。

**必须做的 UI 提示**（合规与责任心）：
- 达到下限时明确提示"不建议再降低摄入"
- 提供"我不会用这个建议替代医生/营养师意见"的免责说明
- 不提供极端饮食法（断食、极低热量）的引导

## 4. 三大营养素分配

**蛋白质优先**（减脂期最关键，保护肌肉）：
- 普通减脂人群：**1.6 g/kg 体重**起步，可到 2.0–2.2 g/kg
- 参考：[Helms et al. 综述](https://europepmc.org/article/MED/34579132)、[蛋白质摄入与瘦体重保持综述](https://www.voprosy-pitaniya.ru/en/jarticles_diet/1063.html)
- 蛋白质热量 = 4 kcal/g

**脂肪**：
- 建议不低于总热量的 20–25%（激素健康）；按 0.8–1.0 g/kg 体重估算
- 脂肪热量 = 9 kcal/g

**碳水**：填满剩余热量
- 碳水热量 = 4 kcal/g

```
目标蛋白(g) = 体重 × 1.6          # 可调 1.6–2.2
目标脂肪(g) = max(体重 × 0.8, 总热量 × 0.20 / 9)
目标碳水(g) = (总热量 − 蛋白×4 − 脂肪×9) / 4
若 目标碳水 < 50 → 提示"热量目标过低，无法同时满足蛋白质和脂肪需求"
```

## 5. 体重趋势的统计学处理（对应需求 P3）

单日体重受水分、盐分、排便、称重时间影响，波动可达 ±1 kg，远大于真实脂肪变化（每天约 0.1 kg）。

**做法**：
1. **7 日移动平均**（trailing 7-day moving average）作为主展示线
2. 单日数据点用小圆点弱化显示
3. 趋势判定用**线性回归斜率**（对最近 14 天做最小二乘拟合），而不是"今天比昨天"
4. 输出人话解读：
   - 斜率换算成"每周变化 X kg"
   - 与目标速度比较：符合 / 过慢 / 过快（过快时提醒掉肌肉风险）
   - 数据点 < 7 天时提示"数据还不够，再记几天"
